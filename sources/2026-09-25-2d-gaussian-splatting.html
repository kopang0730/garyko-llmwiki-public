一句话结论

把原3DGS体积图元替换为三维坐标中的定向二维圆盘，并加透视校正相交渲染与深度/法线约束，在有GT几何的DTU中提升Chamfer；图像PSNR与原3DGS存在取舍（作者ACM imprint v2 pp.2–8 Tables1–5）。

问题定义和接口

输入多视角静态照片、已知内外参与COLMAP点；训练时无需深度真值。输出渲染图、深度/法线与由训练视图深度图融合的mesh。2D指图元自由度而不是图片任务，不能从新视角PSNR推几何准确性（pp.2、4–6）。

方法概述

每片存中心、切平面正交基与两个尺度，交点在局部uv平面评估Gaussian，tile排序作α合成。对斜视退化图元加屏幕足迹下界；纹理监督之外，沿ray深度畸变和盘法线—中位深度法线一致性项约束表面。最后TSDF融合，训练/网格成本须分开记录（pp.4–5 Eq.4–16，p.6 §6.1）。附录p.9的实际深度畸变推导改为NDC平方差，主文公式不能直接当唯一实现。

主要结果与反证

  • DTU 15场，30K平均Chamfer 2DGS .80、3DGS1.96、SuGaR1.33、NeuS .84，训练10.9m对3DGS11.2m和NeuS>12h；同条件Table3的PSNR 2DGS34.52 < 3DGS35.76，模型52MB vs113MB（p.6 Tables1/3）。训练时长不包含已核定的COLMAP与TSDF总账。
  • TnT六场F1 2DGS .32，高于3DGS .09与SuGaR .19，仍低于NeuS .38、Neuralangelo .50；该组作者时间15.5m vs3DGS14.3m（p.6 Table2）。
  • Mip-NeRF360室外RGB PSNR 24.34 < 3DGS24.64、室内30.40 <30.41；SSIM/LPIPS亦略退，且该数据集无GT mesh（p.7 Table4/§6.2）。
  • DTU 15K full Chamfer .83；去法线一致性1.24、去深度畸变.88、用期望深度.94、用SPSR1.07（p.7 Table5）。这些消融说明约束与提取器的贡献，不是2D图元纯因果隔离。

局限或疑问

全不透明表面假设在玻璃失效，高亮区域有孔洞，纹理导向增密牺牲细几何，正则可能磨平细节（p.8 §7/Fig.12）。GPU描述为单RTX3090，缺公开峰值显存、全面渲染延迟与端到端SfM+TSDF分项；未在此轮复现。作者仓库可见而GitHub API license NOASSERTION，具体文件条款待核。

版本与相关页面

正式SIGGRAPH Conference Papers DOI与作者题名已核，PDF是作者托管带arXiv v2页眉的ACM imprint，非ACM下载件；详细全文分析raw/ingest/2026-09-25-2d-gaussian-splatting/analysis.md。原始3DGS以外观/速度为中心，Mip-Splatting以尺度伪影为中心，研究专题以任务和指标分类综合。
