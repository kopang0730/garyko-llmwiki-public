Gaussian Image Representation

目录
  1. 研究问题与范围
  2. 来源库与检索方式
  3. 本轮语料与缺口
  4. 提取与比较规则

核查截止：2026-10-27（America/Los_Angeles）。阶段：evidence_map。这是人工定向补充，不声称系统覆盖或完成全年检索。

研究问题与范围

主问题：将图像表示为二维高斯，在什么任务与预算下，能以更少参数、实际字节或时间保留足够信息？

子问题：哪些自由度是任务冗余；图元分配、结构共享和量化的效果如何区分；重建质量能否转化为下游任务收益；首次构建与重复输出应如何计费？

  • 核心时间窗：2024-01-01至2026-10-27；原始3DGS作为背景链接，不算本批二维核心论文。
  • 纳入：有正式主会或同行评审期刊记录，二维图像高斯为核心表示，且所读全文版本明确。单幅拟合、压缩、大图表示、直接视觉接口与连续超分分组比较。
  • 排除核心：只有预印本／workshop身份；三维空间曲面2DGS；多视光场和多维张量恢复等邻近任务；仅有摘要而没有可核全文者。
  • 正式身份与全文版本分别判断：正式发表但只读到作者稿时，标版本差异；官方补充支持的结论单列。未取得最终稿不等于已读最终版本。

来源库与检索方式

发现入口为web搜索；正式身份优先ECVA/Springer、AAAI、CVF、ACM、ICLR proceedings、IEEE及Crossref。作者页面和代码库用于找到作者稿与实现，不覆盖正式证据。

实际查询包含下列字面式及论文名查验；搜索排序、语言和网页可访问性可能变化，因此本协议可帮助追溯，但不是完整数据库导出的系统检索。

目的查询式
必选论文"GaussianImage" ECCV 2024；"GaussianImage++" paper 2026；"GaussianImage++" site:ojs.aaai.org
新主会"2D Gaussian" "Image" "CVPR 2026"；site:openaccess.thecvf.com/content/CVPR2026 "SGI" "Structured"
前一年"Gaussian" "Image Representation" site:ojs.aaai.org "2025"；按Image-GS和Instant GaussianImage正式题名查验
恢复接口"2D Gaussian" "ICLR" "2026" image；"Pixel to Gaussian" site:iclr.cc/virtual/2026
期刊"GaussianImage" "TPAMI" OR "Transactions on Image Processing"；"Gaussian" "image representation" "Transactions" 2025 2026
当年竞争表征"GaussianImage" "ECCV 2026"；"GaussianImage" site:ecva.net/papers/eccv_2026
定向追查"Large Images Are Gaussians" official code pdf；"Bridging the Gap between Implicit and Explicit Representation" github pdf

去重顺序：DOI → arXiv编号及版本 → 标准化题名。一个论文的作者稿、正式稿和补充不算多篇。

本轮语料与缺口

核心八篇：GaussianImage、GaussianImage++、LIG、Image-GS、Instant GaussianImage、SGI、GaussianVision、ContinuousSR。全部有正式身份；SGI与GaussianVision的作者主文和正式补充分开使用，不能隐去版本差异。

已记录的非核心候选：PA-G2DS、Entropy-Aware Image Representation、光场高斯／像素表示、PIC、GSLR、Fast2DGS、Frequency-Adaptive GaussGrids。前两项全文待补；另有邻域、正式身份或时间窗限制。详情见Gaussian Image Representation Evidence Matrix。

八篇核心加七项非核心记录是本批去重语料，不是搜索引擎所有命中数量。邻域恢复论文及ECCV当年竞争表示仍有覆盖缺口；后续加入须沿用正式身份、全文与版本门，不能直接从引用列表升级为已读。

提取与比较规则

每篇保留原始PDF、可搜索全文和独立分析；Source记录问题、参数、数据、划分、配方、成本、结果、消融、反例及定位。未报告指标留空，不以推测补齐。

质量和成本只做同篇匹配比较。跨篇先分任务，再列分辨率、点数、实际字节、训练／拟合、IO／解码／渲染、GPU、教师和预训练成本。报告最大点数不等于实际点数，原始参数大小不等于独立码流，多尺度摊销不等于单次延迟。

本轮没有训练或性能复现。研究入口是诊断假设，尚未完成新颖性排查；成果与止损条件见二维图像高斯表征：从参数精简到压缩与视觉任务及二维图像高斯表征应优先解决哪种信息与成本瓶颈？。暂不升级为systematic_review或decision_ready。
