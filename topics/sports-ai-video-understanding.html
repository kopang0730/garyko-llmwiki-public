当前综合判断

体育 AI 视频理解的关键价值在于，它把通用视频理解里的“时序推理”压到更具体、更难取巧的结构化任务上：同一个球员要持续被跟踪，多个人之间的交互要被识别，完整场地中的轨迹要能被补全和预测，比赛状态还要能被解释。

sources/2026-04-24-sportsmot 与 sources/2026-04-23-sportmamba 构成第一层：团队运动中的 tracking 不能只依赖线性运动假设和外观 ReID，高速变速、遮挡、球衣相似会把 association 变成核心瓶颈。

sources/2026-04-24-teamtrack 把这个问题扩展到 full-pitch 场景。它提醒我们，真正的体育分析常常需要从局部目标跟踪走到全场空间理解，否则很难支撑站位、队形和战术层判断。

sources/2026-04-24-sportshhi 提供第二层：体育视频理解必须处理高层 human-human interaction。它把篮球和排球里的互动关系做成 benchmark，让模型从“看见人”推进到“理解人与人之间的关系”。

sources/2026-04-24-transportmer 提供第三层：当输入从像素检测转为轨迹后，核心问题变成多智能体时序建模。预测、补全、球位置推断和比赛状态分类可以共享同一个表征，而这正是从 tracking 走向 tactical understanding 的关键中间层。

体育机器视觉文献清单 把这条体育 AI 子线从论文级证据扩展到方向级规划：它把动作识别、姿态估计、tracking、战术分析、裁判辅助、伤病风险、工业部署放在同一张图里，并给出“多模态、可解释、低标注、可部署系统”的选题判断。

2026-07-12 Badminton 全文复核：四层系统与编码器边界

八篇全文证据把羽毛球动作纠正明确拆成四层：shuttle tracking → court/3D reconstruction → hit/phase alignment → action quality assessment。TrackNet 系列只覆盖第一层及短断轨修复；FineCausal 位于第四层，二者之间仍需要球场映射、姿态和击球阶段桥接。sources/2026-04-25-opencap 提供双视角受控采集下的生物力学参考分支：joint-angle MAE 4.5°，100 人 field screening AUC 0.90，可输出 3D pose、joint moments 与 muscle activation；它尚未覆盖单目广播、高速拍球接触或实时纠正。

  • TrackNet 的高随机帧 split 指标存在近重复泄漏风险；TrackNetV3 以 accuracy 97.51%、F1 98.56% 成为当前最强 demo baseline，但 repaired points 必须保留来源标记；TrackNetV4 的 motion adapter 带来约 0.6–1.4 点稳定小增益。
  • TrackMAE 提供 motion-aware RGB 表征；BlockGCN 提供轻量 topology-aware GCN；ProtoGCN 提供细粒度 prototype classifier；SkateFormer 提供 2.03M 参数、11.46ms 的 joint-time Transformer。四者均未直接验证羽毛球错误诊断。
  • FineCausal 的 GAT + masked temporal attention 在跳水 AQA 上改善 R-L2，当前证据支持“阶段化结构注意力”，尚未支持真实因果归因或教练可用反馈。

因此，体育 AI roadmap 的近期实验应固定 10 个真实 clip，保存 raw xy / confidence / repair mask / repaired xy / hit frame / pose，以 TrackNetV3 为主、V4 为成对增强，并用专家 rubric 评估错误检测、阶段定位和反馈可执行性。

基础表征与球员 association 补充

  • SportMamba：SportsMOT HOTA 77.3，最高；IDF1/AssA 77.7/66.8 仍低于 Deep-EIoU 的 79.8/67.7。贡献混合 Mamba+MHSA motion model 与 HA-EIoU/dynamic EMA association，不能归因为 SSM 单项优势。
  • ST-GCN：Kinetics skeleton-only 30.7/52.8 top-1/top-5，RGB 57.0/77.3；RGB+Flow+Skeleton 从 70.3/71.5 提升到 71.7，直接支持 pose 与视觉互补。
  • TimeSformer：K400 78.0、0.59 TFLOPs、121.4M params；96-frame clip 跨 102.4 秒，但 7 分钟视频仍靠约 4 个 clip 平均，不代表全片结构推理。
  • VideoMAE：域内无标签预训练在 K400/SSv2 达 80.0/69.6；90% tube mask 对小运动目标有遮光风险。ViT-H headline 为 633M、7397 GFLOPs×4 clips×3 crops，不适合直接部署。

这四篇把 demo backbone 选型收窄为：SportMamba 只服务 player ID/crop；ST-GCN 作为轻量 skeleton baseline；VideoMAE 先用羽毛球无标签视频做域内预训练，再与 pose/trajectory 融合；TimeSformer 只作为 RGB Transformer 对照。四者都未直接验证 shuttle、hit frame 或动作纠正。

Tracking → trajectory → interaction 的接口链

  • SportsMOT：240 clips、150,379 帧、1,629,490 boxes；MOTA 可到约 96，AssA 仍只有 50–60 多。MixSort-Byte HOTA/IDF1/AssA 65.7/74.1/54.8，直接支持 association 是瓶颈。
  • TeamTrack：279,900 帧、4,374,900 boxes、4K–8K 全场视角；平均 HOTA 61.9，却在篮球不同视角间出现 76.2/42.9/65.7，说明视角、设备与项目域需要分层报告。
  • TranSPORTmer：消费已清洗场地坐标，完成预测/补全/不可见 agent inference/状态分类；足球 ball 100% hidden 时 ADE 3.89→2.71m，分轴 attention 88ms vs flattened 340ms。统一的是架构接口，任务仍分别训练。
  • SportsHHI：11,398 帧、50,649 有向人对交互；最强 ViT-B HHICls/HHIDet mAP 10.69/4.93。它证明 tracking 后还需要 interaction layer，低 mAP 也说明局部关系仍困难。

这四篇建立明确依赖链：player detection/ID → calibrated field trajectories → multi-agent prediction/state → directed interaction semantics。每层误差都会向后传播；其中没有一篇覆盖 shuttle tracking、contact frame、racket 或技术质量。

MultiSports 在 tracking 与 interaction 之间补上 actor action-tube 层：3,200 clips、37,701 instances、约 902K boxes；SlowFast frame-mAP 27.72，video-mAP@0.5 仅 9.65。系统证据链应扩展为 tracking/ID → actor action tubes → calibrated trajectories/state → interaction → quality/feedback。一个足球触球约 0.5 秒却可能需要最多 5 秒上下文，也直接支持 hit-centered clip 配合较长 pre/post context。

SoccerNet-GSR 又把链条前端补成 camera/court calibration → player ID → pitch game state：200×30s clips、9.37M line points、2.36M athlete positions；image-plane HOTA 57.64 到完整 GS-HOTA 22.26 的落差量化了 calibration、team、jersey 与 association 的级联成本。体育系统必须先把 image-plane evidence 映射到可靠场地坐标，再进入 action/interaction 层。

Event2Tracking 在 game-state 之后加入事件辅助轨迹修复：700 games train/52 eval，60s player/ball mADE 3.22/3.51m，对 STT 3.62/5.46m。事件流包含 on-ball event 的时间、位置和身份，既是有效 side channel，也是强上游依赖；5Hz 与 meter-level error 只支持场地状态，不能替代高速 contact tracking。

FineSports / LOGO / SportsCap / TPT 把动作层拆为四个不同接口：目标人 action tubes（FineSports 10K clips，video-mAP@0.5 24.31）、多人长时 AQA（LOGO 200 videos，最佳 ρ 0.5599）、运动特定 3D pose→attributes（SportsCap 640 videos/110K frames，PCK-0.5 96.0）和无步骤标签的 part-wise relative AQA（TPT MTL-AQA ρ 0.9607）。这些数字分别依赖球衣提示、sample split、closed pose priors 或真分 exemplar，不能合并为统一“体育理解”能力。

Sports-QA 在结构化感知之后增加 constrained reasoning 层：94,073 QA pairs，AFT accuracy/F1 59.2/25.6，Temporal accuracy 仅 35.3；BlindQA 仍有 43.7 accuracy。它支持 question-conditioned multi-scale retrieval，同时模板生成、random video split 与闭集答案限制了开放式教练/裁判推理结论。

X-VARS 将 reasoning 进一步推进到专家解释：10K+ foul clips/22K QA、70+ referees，解释盲评 human/X-VARS 为 4.0/3.8。它同时暴露 classifier prediction-token shortcut、LLM hallucination、ChatGPT extraction coupling 与 explanation faithfulness 缺口；领域解释质量不能替代判罚校准和证据审计。

TacticAI / MatchVision / MonoTrack / TrackNetV2 则给出系统分层对照：TacticAI 只消费结构化角球状态；MatchVision 以 1 FPS 做共享足球编码；TrackNetV2 在 2D shuttle layer 达 31.84 FPS、unseen-match accuracy 85.2%；MonoTrack 才串接 court/2D shuttle/hit/3D，HitNet F1 0.946，真实端到端 reprojection 23.3–37.1 px。真正接近羽毛球 demo 的直接证据来自后两者。

SoccerNet-Tracking 将足球底层误差拆成 detection 与 association：GT boxes 下 FairMOT HOTA 71.500，end-to-end 43.911，域内微调后 57.882。该差距证明后续 GSR、trajectory repair 和 tactics 必须继承上游 DetA/AssA 置信度；bbox continuity 不能直接视为真实场地状态。

Active Learning / HITL Retrieval / RefereeBench / 单场地原型 提供人机成本与可靠性压力测试：entropy selection 的 16% 是模拟 oracle 数据比例；检索的 5 个 labels 由 class 自动生成；RefereeBench closed/open overall 61.09/47.07 且规则 RAG 退化；单场地足球 0.225–0.499m 只测 keypoint/homography。真实专家工时、负例、拒答和跨场地 split 必须独立记录。

Broadcast2Pitch 把 GSR follow-up 推到 GS-HOTA 61.48（原 baseline 22.26、强 follow-up 55.82）：joint geometry 58.51，再加 IDATR 到 61.48。LLaMA identity 相对 CLIP 仅 61.48 vs 60.13，却增加生成式输出和成本；VLM cue 应作为可校准属性输入，不应替代严格 identity supervision。

SoccerNet challenge reports / MOT4MOT / calibration resource 提供历史协议审计：年度榜单混合不同预训练、ensemble 和预算；MOT4MOT 私有榜 HOTA 66.27，但公开 test frames 被人工选作 validation；CCBV-SN 用商业 teacher 生成 12K pseudo calibrations，SoccerNet calibration/player-location 无 GT。私有榜、公开 test、伪标签资源必须分级引用。

SoccerNet-v2 / VARS / PathCRF / WEAR 补齐四种系统接口：v2 用 500 场/764h/约1600人时建立事件、镜头与回放任务；VARS 在 contact-centered 多视角 clips 上 foul/severity BA 0.45/0.34；PathCRF 在 7 场 tracking 上 event F1 75.69、非法转移0%；WEAR 以22人四肢IMU+第一视角视频做 HAR。它们分别缺精细接触、整场发现、广域泛化和动作质量标签。

Automated Offside Detection 2021 的 8 页全文把早期规则原型拆成 calibration → YOLO localization → pitch projection → ball-speed pass detection → team assignment → Kalman/Hungarian tracking → rule function。双固定广角相机覆盖 3 场比赛，最终只评 20 个 30 秒平衡片段；作者报告 precision/recall/F1 为 60/66.7/63.1%，但 Table 1 的 TP/FP/FN/TN=6/3/4/7 复算应为 66.7/60/约63.2%，说明 precision/recall 顺序写反。Algorithm 1 也只检查 receiver，未完整覆盖与球位置比较、干扰对手、反弹获利和 body-part rule。因此它是结构化 referee-assist pipeline 的奠基证据，也是级联误差压力测试，不支持自动执法。

Pose / hierarchy / AQA 证据边界

  • AthletePose3D：体育域训练把 TCPFormer MPJPE 213.64→约65mm，但 3D velocity correlation 仅 0.29/0.12；位置较准仍不足以支持高速末端运动学。
  • AthleticsPose：subject-disjoint 户外训练将 MPJPE 149.38→41.99mm，knee-drive velocity RMSE 0.77m/s 且系统性高估；侧视和大目标更可靠。
  • FineGym：303 场/708 小时、32,697 sub-actions；Gym288 mean/top-1 46.5/83.1 暴露长尾，sub-action localization mean AP 仅 9.6。
  • FineDiving：3,000 clips，TSA 用已知 dive number + reference score 达 Spearman 0.9203；严格 transition AIoU@0.75 34.31，sample split 未说明 athlete/source isolation。

它们支持 pose→阶段→reference comparison 的训练反馈接口，同时要求 athlete/session/court/camera-disjoint、阶段级 rubric 和高阶运动学误差传播。总分相关性与 attention visualization 都不能直接写成因果纠错解释。
